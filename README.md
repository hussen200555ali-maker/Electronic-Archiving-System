# نظام الأرشفة الإلكتروني — Electronic Archiving System

نظام أرشفة إلكتروني (تطبيق سطح مكتب) مبني بلغة **C#** على **.NET Framework 4.8** باستخدام **Windows Forms + DevExpress**، مع قاعدة بيانات **SQL Server 2019** و**Entity Framework 6**. يتيح النظام حفظ الوثائق والملفات (PDF / Word ...) بشكل **مشفر داخل قاعدة البيانات** مع إدارة صلاحيات متعددة المستويات وبحث شامل وتقارير.

## الميزات الرئيسية

- **تسجيل الدخول** مع جلسة مستخدم وتحديد الدور.
- **رفع عدة ملفات** (PDF, Word, ...) وتخزينها كـ `varbinary(max)` داخل قاعدة البيانات بعد **تشفير AES**.
- **إدارة الأقسام** (إضافة / تعديل / حذف / طباعة).
- **إدارة فئات الأرشيف والسجلات** مع ربطها بالأقسام والمستخدمين.
- **عرض وفتح الملفات** مباشرة (يتم فك التشفير وكتابة نسخة مؤقتة ثم فتحها).
- **بحث شامل** عن الملفات بالاسم أو المُرسل أو المستلم أو التاريخ أو القسم.
- **تصدير نتائج البحث إلى Excel** وطباعة التقارير (معاينة الطباعة).
- **إدارة المستخدمين** مع مؤشر قوة كلمة المرور.
- **إحصائيات لوحة رئيسية** (عدد الأقسام والمستخدمين والفئات وحجم البيانات).
- **نسخ احتياطي لقاعدة البيانات** وإعدادات اتصال قابلة للاختبار والحفظ.
- **نظام صلاحيات (3 أدوار)**:
  - **مدير** — يرى ويدير كل شيء (المستخدمون، الأقسام، جميع السجلات).
  - **مدير قسم** — يرى سجلات قسمه فقط ويضيف موظفين لقسمه.
  - **موظف** — يرى ويدير ما أضافه فقط، وتُخفى مناه الإدارة عنه.

## هيكل المشروع

```
Electronic Archive/
├── Program.cs              # نقطة البداية
├── Main.cs                 # النافذة الرئيسية (تنقل плитات)
├── AddPage/                # نوافذ الإضافة والتعديل (ملفات، مستخدمون، أقسام، فئات)
├── Pages/                  # نموذج Entity Framework (.edmx) وصفحات المستخدم
├── PL/                     # طبقة العرض (دخول، عرض الملفات، بحث، إعدادات)
├── Helpers/                # أدوات مساعدة (تشفير AES، إدارة الملفات والمجلدات)
└── Properties/             # إعدادات المشروع
```

## قاعدة البيانات

5 جداول في SQL Server:

| الجدول | الوصف |
|---|---|
| `TB_Dep` | الأقسام |
| `TBUsers` | مستخدمو النظام وأدوارهم |
| `TBArchiveCat` | فئات/سجلات الأرشيف |
| `TBArchive1` | السجلات الوثائقية (بيانات الوثيقة) |
| `ArchiveFile` | الملفات المرفوعة (`FileData varbinary(max)`) |

> تتم كل العمليات (إضافة/بحث/حذف) عبر **Entity Framework 6 + LINQ**.

## التشغيل

1. افتح `Electronic Archive.sln` في Visual Studio.
2. استعد الحزم NuGet (`Restore Packages`).
3. حدّث سلسلة الاتصال في `App.config` لتشير إلى نسخة SQL Server الخاصة بك (أو استخدم شاشة الإعدادات داخل البرنامج).
4. شغّل المشروع — عند أول تشغيل يُطلب إضافة قسم ومستخدم أول (مدير).
